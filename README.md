## Featured Projects

### 🔋 [Real-Time Li-Ion Battery SOC Estimation using EKF](https://github.com/adityaatil/Real-Time-Li-Ion-Battery-SOC-Estimation-using-Extended-Kalman-Filter-EKF-)
An ESP32-based real-time battery monitoring system combining **Coulomb Counting, an experimentally obtained OCV-SOC lookup table, INA219 current sensing, voltage measurement, and an Extended Kalman Filter**. Tested with no-load, LED-load, and DC-motor-load conditions.

### 🔐 [Smart Door Lock using LPC1768 and RTX RTOS](https://github.com/adityaatil/Smart-Door-Lock-System-ARM-CORTEX-M-3-)
A task-based smart door lock system for the **ARM Cortex-M3 LPC1768**. It uses UART password input, a 16×2 LCD, LED status indication, retry handling, and Keil RTX tasks.

### ☀️ [Portable Solar Phone Charger](https://github.com/adityaatil/Solar-Phone-Charger)
A hardware prototype that converts variable solar-panel DC voltage into a regulated **5 V USB output** using an LM2576 buck converter. The project includes circuit work, PCB design, and a working model.

### 📡 [ESP32 Water Tank Monitor with Blynk IoT](https://github.com/adityaatil/Water-Tank-monitor-using-blynk-app-)
An IoT project using an **ESP32 and HC-SR04 ultrasonic sensor** to measure tank level and display the percentage remotely in the Blynk mobile app.

### 🔑 [ESP32 Keypad Door Lock](https://github.com/adityaatil/Door-lock-using-esp32-keypad)
A password-based access-control prototype using an ESP32, 4×4 keypad, servo motor, and buzzer.

### 🔋 [Li-Ion SOC Estimation using the OCV Method](https://github.com/adityaatil/SOC-estimation-by-OCV-method)
An ESP32 project that measures battery voltage through an ADC and voltage-divider circuit and estimates State of Charge using an OCV lookup approach.

### 🎯 [Missile Launching Toy — Product Design Project](https://github.com/adityaatil/Missile-Launching-Toy)
A semi-automatic toy design project covering problem definition, functional decomposition, concept generation, resource calculations, motor selection, and virtual implementation.
